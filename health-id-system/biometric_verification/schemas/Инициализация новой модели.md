# Примеры запросов
## 1. Инициализация первой версии (initial)
```bash
curl -X POST "http://localhost:8000/api/governance/model-config" \
  -H "Content-Type: application/json" \
  -d '{
    "config": {
      "face_size": [128, 128],
      "face_padding": 20,
      "min_face_size": 64,
      "model_version": "face_v0.0.1",
      "match_threshold": 0.85,
      "detector_backend": "haar"
    },
    "change_type": "initial",
    "change_description": "Базовая инициализация модели верификации",
    "created_by": "admin"
  }'
```
## 2. Обновление (наследование от последней активной)
```bash
curl -X POST "http://localhost:8000/api/governance/model-config" \
  -H "Content-Type: application/json" \
  -d '{
    "config": {
      "face_size": [128, 128],
      "face_padding": 20,
      "min_face_size": 64,
      "model_version": "face_v0.0.2",
      "match_threshold": 0.87,
      "detector_backend": "mtcnn"
    },
    "change_type": "update",
    "change_description": "Повышен порог совпадения, сменён детектор на MTCNN",
    "created_by": "ml_engineer"
  }'
```
