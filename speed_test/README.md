# speed_test.py — консольный тест скорости скачивания

Небольшой скрипт на Python (только стандартная библиотека, ничего устанавливать не нужно),
который измеряет скорость скачивания одного URL: делает 10 последовательных GET-запросов,
дожидается полного ответа на каждый и считает итоговую скорость.

## Требования

- Python 3.9+ (проверено на 3.10–3.13).
- Доступ в интернет (или локальный сервер, если тестируете свой адрес).

## Запуск

```bash
python speed_test.py <URL> [--timeout 60]
```

Примеры:

```bash
# внешний тяжёлый файл
python speed_test.py https://icons8.ru/photos/photo/t-shirt-on-clothes-hanger--5db0c303f510fd0001e43c17

# локальный сервер, поднятый вашим приложением
python speed_test.py http://127.0.0.1:8088/static/some-large-file.bin

# увеличить таймаут для медленного канала
python speed_test.py https://speed.hetzner.de/100MB.bin --timeout 120
```

Аргументы:

| Аргумент    | Обязателен | Описание                                        | По умолчанию |
|-------------|------------|-------------------------------------------------|--------------|
| `url`       | да         | Адрес для проверки (ссылка на тяжёлый файл)     | —            |
| `--timeout` | нет        | Таймаут одного запроса, секунд                  | `60`         |

## Что делает скрипт

1. Выполняет 10 GET-запросов строго последовательно (не параллельно).
2. Каждый раз дочитывает тело ответа до конца, кусками по 64 КиБ — объём считается
   по фактически полученным байтам, а не по заголовку `Content-Length`.
3. Замеряет время каждого запроса (от старта до полного получения тела).
4. Итоговая скорость = суммарный объём всех ответов / суммарное время всех запросов.

## Единицы измерения

- **Объём** — МиБ (мебибайты), 1 МиБ = 1 048 576 байт (2^20).
- **Скорость** — показываются обе величины:
  - **МиБ/с** — мебибайты в секунду (фактическая скорость скачивания);
  - **Мбит/с** — мегабиты в секунду (1 байт = 8 бит). Удобно сверять
    с тарифом провайдера, который почти всегда указывается именно в Мбит/с.

Пример строки итога:

```
--- Итог ---
Скачано всего:      97.66 МиБ
Среднее время:      8.42 с на запрос
Средний размер:     9.77 МиБ на ответ
Скорость:           11.60 МиБ/с =   92.80 Мбит/с
```

## Как читать результат

- Если скорость в МиБ/с умножить на 8, получится Мбит/с — как в примере выше.
- Первый запрос может быть заметно медленнее остальных: тратится время на DNS и
  установку TLS-соединения. Если нужна «чистая» скорость канала — запустите скрипт
  дважды подряд и ориентируйтесь на второй запуск.
- Разброс по запросам больше ~20–30% обычно означает нестабильную сеть или
  ограничение на стороне сервера, а не проблемы у вас.

## Коды выхода

- `0` — все 10 запросов выполнены успешно, итог напечатан.
- `1` — ошибка сети или HTTP (например, 404, 503, таймаут) на любом из запросов;
  скрипт прерывается на первом сбое, результаты не печатаются.

## Ограничения

- Поддерживаются только GET-запросы по HTTP/HTTPS.
- Если сервер отдаёт ответ в сжатом виде (gzip/deflate), `urllib` распаковывает его
  «прозрачно» — объём считается по распакованным данным, что может завысить скорость
  по сравнению с объёмом по сети.
- Скрипт не измеряет задержку (ping/latency) — только пропускную способность.
